## 横浜市中小企業融資制度「[小規模企業資金繰り安定サポート資金](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/shikinguri-antei.html)」のご案内

横浜市では、市内中小企業および小規模事業者の皆様の事業活動に必要な資金調達を支援するため、「横浜市中小企業融資制度」を提供しております。本稿では、特に小規模企業者の資金繰り安定化を目的とした「小規模企業資金繰り安定サポート資金」について、その詳細をご案内いたします。

### 特徴

本資金の最大の特徴は、**経常運転資金の一部について、毎月の返済を伴わない一括返済の短期資金（期間1年以内）を、要件を満たせば更新により継続して利用できる**点にあります。これにより、実質的に長期の運転資金と同様の効果が期待でき、**疑似資本的な資金調達**として資金繰りの安定化を図ることが可能です。

### 融資条件

小規模企業資金繰り安定サポート資金の主な融資条件は以下の通りです。

| 項目         | 内容                                                                 |
| :----------- | :------------------------------------------------------------------- |
| **融資対象者** | [横浜市中小企業融資制度の融資申込要件](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/yushi.html#moushikomi)を全て満たす小規模企業者<br>**【追加要件】** 次の全ての要件を満たす事業者<br>1. 1期以上の決算（確定申告）を行っている<br>2. 既存の借入について条件変更等による返済緩和を行っていない<br>3. ＜法人＞直近決算で債務超過でなく、経常利益を計上している<br>   ＜個人事業主＞直近の確定申告における申告所得額が200万円以上 |
| **資金使途**   | 運転資金                                                             |
| **融資額**     | 100万円以上2,000万円以内（ただし、直近決算における平均月商の2倍以内）   |
| **利率（年利）** | 取扱金融機関の所定利率                                                 |
| **融資期間**   | 運転資金 1年以内（一括返済）                                           |
| **担保**       | 必要に応じて                                                         |
| **保証料率**   | 年0.35％～1.80％<br>※横浜市信用保証協会による保証料割引（0.1％）適用後の料率 |
| **その他**     | ※上記の融資対象者要件（追加要件含む）を満たす場合、**更新により継続利用が可能**です。<br>※1・2回目の更新時は、追加要件3.を満たしていない場合でも更新可能な場合があります。<br>※申込時点で本資金および信用保証協会（横浜市以外の信用保証協会も含む）の保証付き短期継続融資を利用していないことが必要です。 |

**※小規模企業者とは**：常時使用する従業員数が20人以下（卸売業・小売業・サービス業は5人以下）の事業者を指します。ただし、サービス業のうち宿泊業および娯楽業は従業員20人以下の事業者が対象となります。

### 必要書類

お申込みにあたっては、原則として以下の書類をご提出いただきます。

1.  信用保証委託申込書（横浜市信用保証協会所定様式）
2.  申込人（個人・法人）および連帯保証人（※1）の印鑑証明書（※2, 3）
3.  納税証明書（※2）、または領収書の写し、eLTAXや地方税お支払いサイトの納付済確認画面
4.  決算書（確定申告書）の写し（原則、直近2期分）
5.  【法人の場合】履歴事項全部証明書（商業登記簿謄本）または登記情報提供サービスで取得したもの（※2, 3）
6.  許認可証等の写し（許認可等が必要な事業の場合）
7.  短期継続保証（けいぞく）申込人資格要件確認書兼モニタリング報告書【協会様式】

*   ※1：連帯保証人が必要となる場合があります。
*   ※2：各種証明書は発行後3ヶ月以内の最新のものをご用意ください。納税証明書は[オンライン申請](https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/shizei-shomei/online/gaiyou.html)も可能です。
*   ※3：横浜市信用保証協会への申込時は写しでの提出が可能な場合があります。
*   ※7の様式については、横浜市信用保証協会のウェブサイト等でご確認ください。

### 融資実行までの流れ

融資実行までの標準的な手続きは以下の通りです。

1.  **ご相談・お申込み**: お取引のある、または最寄りの取扱金融機関にご相談の上、必要書類を提出し、お申込みください。
2.  **金融機関による審査**: 取扱金融機関にて融資審査が行われます。
3.  **信用保証協会による保証審査**: 金融機関からの依頼に基づき、横浜市信用保証協会にて保証審査が行われます。
4.  **融資実行**: 金融機関および信用保証協会の審査を経て承認された場合、取扱金融機関より融資が実行されます。

※本制度のご利用にあたっては、取扱金融機関および横浜市信用保証協会の審査が必要です。記載内容は概要であり、融資実行・保証承諾をお約束するものではありません。
