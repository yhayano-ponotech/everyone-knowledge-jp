## 横浜市中小企業融資制度「[貿易振興金融](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/boueki.html)」のご案内

横浜市では、市内中小企業の皆様の事業活動を支援するため、輸出入等の貿易取引に必要な短期資金の調達を円滑化することを目的とした「貿易振興金融」制度を提供しております。本稿では、当制度の詳細についてご案内いたします。

### 融資の対象となる方

以下の要件を満たす**貿易関係者**が対象となります。

*   横浜市内に**1年以上主たる営業所**を有する
*   **資本金3億円以下** または **従業員300人以下**

※NPO法人は対象外です。

### 融資条件

本制度には、資金使途に応じて以下の4種類の資金があります。

#### 1. 輸出資金

| 項目         | 内容                                                       |
| :----------- | :--------------------------------------------------------- |
| **資金使途**   | 輸出契約に基づく貨物の買取、生産、加工又は集荷のための資金           |
| **融資額**     | 1件あたり7,000万円以内                                     |
| **融資期間**   | 4か月以内                                                  |
| **利率（年利）** | 年1.7％以内                                                |
| **返済方法**   | 関係荷為替手形の金融買取代金又はTT送金による輸出貨物代金の入金により返済 |

#### 2. 輸入資金

| 項目         | 内容                                                                                                                                                                                                                                                         |
| :----------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**   | 輸入契約に基づいて行う次の種別の資金<br>**A種**: a. 信用状開設に必要な保証金, b. 輸入担保荷物貸渡に必要な保証金<br>**B種**: 輸入手形（一覧払・ユーザンス）の決済資金<br>**C種**: 送金決済（TT送金決済）に必要な資金                                                 |
| **融資額**     | 1億円以内                                                                                                                                                                                                                                                    |
| **融資期間**   | **A種**: 2か月以内<br>**B種及びC種**: 6か月以内<br>※A種・B種併用の場合はB種を適用                                                                                                                                                                                  |
| **利率（年利）** | 年1.7％以内                                                                                                                                                                                                                                                    |
| **返済方法**   | **A種**: 信用状又は輸入担保荷物貸渡債務完了時、金融機関から返済を受けた保証金により返済<br>**B種及びC種**: 融資期間内であっても輸入貨物が売却された場合は直ちに返済                                                                                                       |

#### 3. 国際入札保証資金

| 項目         | 内容                                                                 |
| :----------- | :------------------------------------------------------------------- |
| **資金使途**   | 国際入札に伴う物品の輸出又は輸入に係る保証金に充当する資金（現金又は送金支払に限る） |
| **融資額**     | 5,000万円以内                                                        |
| **融資期間**   | 6か月以内                                                            |
| **利率（年利）** | 年1.7％以内                                                          |
| **返済方法**   | 先方から返還を受けた保証金により返済                                   |

#### 4. 倉庫・港湾運輸資金

| 項目         | 内容                                                                                                   |
| :----------- | :--------------------------------------------------------------------------------------------------- |
| **資金使途**   | 輸出入荷物を取り扱う倉庫業者、港湾運送業者（陸送、海上運送、航空運送）が必要とする運転資金                 |
| **融資額**     | 5,000万円以内                                                                                          |
| **融資期間**   | 1年以内                                                                                              |
| **利率（年利）** | 年1.7％以内                                                                                            |
| **返済方法**   | 一括返済又は割賦返済                                                                                     |
