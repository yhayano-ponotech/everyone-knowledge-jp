## 横浜市中小企業融資制度「[経営安定資金](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/keian.html)」のご案内

横浜市では、市内中小企業および小規模事業者の皆様の事業活動を支援するため、「横浜市中小企業融資制度」を提供しております。本稿では、様々な要因により経営の安定に支障が生じている事業者を対象とした「経営安定資金」について、その詳細をご案内いたします。

### 経営安定資金とは

経営安定資金は、売上の停滞、取引先の倒産、売上高や利益率の減少、既往借入金の返済負担、あるいは自然災害による被害など、特定の経営課題に直面している中小企業者を対象とした融資制度です。事業の安定化や再建に必要な運転資金および設備資金としてご利用いただけます。

### 融資条件

経営安定資金の主な融資条件は以下の通りです。

| 項目         | 内容                                                                 |
| :----------- | :------------------------------------------------------------------- |
| **融資対象者** | [横浜市中小企業融資制度の融資申込要件](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/yushi.html#moushikomi)を全て満たし、かつ以下の**追加要件**のいずれかに該当する中小企業者<br>1. 売上の停滞等により経営に支障を生じている**横浜市中央卸売市場の仲卸業者**<br>2. **セーフティネット保証1号または2号**の認定を受けた方、または**取引先の倒産**により経営に影響を受けている方<br>3. 最近3か月又は6か月の**純売上高もしくは粗利率（売上高総利益率）**が、最近5か年のいずれかの年の同期と比較して、**減少**している<br>   *※最近3・6か月とは申込月の前々月を含む3・6か月*<br>4. 横浜市中小企業融資又は横浜市信用保証協会が保証した既往の借入があり、本資金による**借換**により、毎月の返済負担の軽減が図られ、安定的経営が見込まれる<br>5. **風水害等の被害**を受けた |
| **資金使途**   | 運転資金及び設備資金<br>（融資対象者5については事業の再建に必要な資金に限る） |
| **融資額**     | 2億8,000万円以内（組合等は4億8,000万円以内）                           |
| **利率（年利）** | **固定金利：年2.1％以内**                                               |
| **融資期間**   | 運転資金：10年以内<br>設備資金：10年以内<br>（いずれも据置期間12か月以内を含む） |
| **担保**       | 必要に応じて                                                         |
| **保証料率**   | 年0.45％～1.90％ （本資金に対する横浜市の保証料助成はありません）          |

### 必要書類

お申込みにあたっては、原則として以下の書類をご提出いただきます。

**【全対象者共通】**

1.  信用保証委託申込書（横浜市信用保証協会所定様式）
2.  申込人（個人・法人）および連帯保証人（※1）の印鑑証明書（※2, 3）
3.  納税証明書（※2）、または領収書の写し、eLTAXや地方税お支払いサイトの納付済確認画面
4.  決算書（確定申告書）の写し（原則、直近2期分）
5.  【法人の場合】履歴事項全部証明書（商業登記簿謄本）または登記情報提供サービスで取得したもの（※2, 3）
6.  許認可証等の写し（許認可等が必要な事業の場合）
7.  【設備資金の場合】見積書およびレイアウト・カタログ等の写し

*   ※1：連帯保証人が必要となる場合があります。
*   ※2：各種証明書は発行後3ヶ月以内の最新のものをご用意ください。納税証明書は[オンライン申請](https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/shizei-shomei/online/gaiyou.html)も可能です。
*   ※3：横浜市信用保証協会への申込時は写しでの提出が可能な場合があります。

### 融資実行までの流れ

融資実行までの標準的な手続きは以下の通りです。

1.  **ご相談・お申込み**: お取引のある、または最寄りの取扱金融機関にご相談の上、必要書類を提出し、お申込みください。
2.  **金融機関による審査**: 取扱金融機関にて融資審査が行われます。
3.  **信用保証協会による保証審査**: 金融機関からの依頼に基づき、横浜市信用保証協会にて保証審査が行われます。
4.  **融資実行**: 金融機関および信用保証協会の審査を経て承認された場合、取扱金融機関より融資が実行されます。

※本制度のご利用にあたっては、取扱金融機関および横浜市信用保証協会の審査が必要です。記載内容は概要であり、融資実行・保証承諾をお約束するものではありません。
