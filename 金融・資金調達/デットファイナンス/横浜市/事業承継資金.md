## 横浜市中小企業融資制度「[事業承継資金](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/jigyousyoukei.html)」のご案内

横浜市では、市内中小企業および小規模事業者の皆様の事業活動を支援するため、「横浜市中小企業融資制度」を提供しております。本稿では、円滑な事業承継を資金面から支援する「事業承継資金」について、その詳細をご案内いたします。

### 事業承継資金とは

事業承継資金は、事業の引継ぎや経営権の集約、M&Aなど、事業承継に関わる様々な場面で必要となる資金調達を支援する融資制度です。後継者だけでなく、事業承継計画を進める現経営者や、従業員による買収（EBO）を行う個人なども対象となります。横浜市による保証料の助成があり、利用者の負担軽減が図られています（一部対象者を除く）。

### 融資条件

事業承継資金の主な融資条件は以下の通りです。

| 項目         | 内容                                                                 |
| :----------- | :------------------------------------------------------------------- |
| **融資対象者** | [横浜市中小企業融資制度の融資申込要件](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/yushi.html#moushikomi)を全て満たし、かつ以下の**追加要件**のいずれかに該当する中小企業者<br>1. 事業継続が困難な事業者から事業用資産等の譲渡を受けて事業を承継しようとする**後継者**<br>2. 経営権集約目的で、**持株会社**によって事業会社の株式を集約化し事業を承継しようとする<br>3. 事業承継を実施した後、**議決権株式取得資金、事業用資産取得資金、相続税・贈与税の納税資金等**を必要とする（代表者個人による借入も可）<br>   *(国の「経営承継関連保証制度」又は「特定経営承継関連保証制度」対象)*<br>4. **M&A等による事業承継**をこれから実施するため、事業継続困難な事業者の株式や事業用資産等の取得資金を必要とする<br>   *(国の「経営承継準備関連保証制度」対象)*<br>5. **EBO（従業員による買収）等**による事業承継をこれから実施するため、事業継続困難な事業者の株式や事業用資産等の取得資金を必要とする（**事業を営んでいない個人**に限る）<br>   *(国の「特定経営承継準備関連保証制度」対象)*<br>6. 横浜市信用保証協会、（公財）横浜企業経営支援財団、取扱金融機関又はその他認定経営革新等支援機関の支援を受け、**10年以内の事業承継計画**を策定し、計画実行に取り組む<br>7. 被後継者から事業を引き継いで**3年を経過していない** |
| **資金使途**   | **【対象者1】** 事業承継に伴い必要な設備資金（付随する運転資金含む）<br>**【対象者2】** 持株会社が被後継者の保有する事業会社の発行済議決権株式総数の3分の2以上を一括で取得する設備資金<br>**【対象者3～5】** 対象となる国の保証制度の定めによる<br>**【対象者6】** 事業承継計画の実施に必要な運転資金及び設備資金<br>**【対象者7】** 運転資金及び設備資金 |
| **融資額**     | 2億8,000万円以内                                                        |
| **利率（年利）** | 取扱金融機関の所定利率                                                 |
| **融資期間**   | 運転資金：10年以内<br>設備資金：15年以内<br>（据置期間：通常12か月以内。対象者2は**18か月以内**） |
| **担保**       | 必要に応じて                                                         |
| **保証料率**   | **【対象者1～4, 6, 7】**<br>・助成前：年0.45％～1.90％<br>・助成後：**年0.20％～1.65％**（横浜市が**年0.25％**助成）<br>**【対象者5】**<br>・助成前：年1.15%<br>・助成後：**年0.90%**（横浜市が**年0.25％**助成） |

### 必要書類

お申込みにあたっては、原則として以下の書類をご提出いただきます。

**【全対象者共通】**

1.  信用保証委託申込書（横浜市信用保証協会所定様式）
2.  申込人（個人・法人）及び連帯保証人（※1）の印鑑証明書（※2, 3）
3.  納税証明書（※2）、または領収書の写し、eLTAXや地方税お支払いサイトの納付済確認画面
4.  決算書（確定申告書）の写し（原則、直近2期分）
5.  【法人の場合】履歴事項全部証明書（商業登記簿謄本）または登記情報提供サービスで取得したもの（※2, 3）
6.  許認可証等の写し（許認可等が必要な事業の場合）
7.  【設備資金の場合】見積書およびレイアウト・カタログ等の写し

*   ※1：連帯保証人が必要となる場合があります。
*   ※2：各種証明書は発行後3ヶ月以内の最新のものをご用意ください。納税証明書は[オンライン申請](https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/shizei-shomei/online/gaiyou.html)も可能です。
*   ※3：横浜市信用保証協会への申込時は写しでの提出が可能な場合があります。

### 融資実行までの流れ

融資実行までの標準的な手続きは以下の通りです。

1.  **ご相談・お申込み**: お取引のある、または最寄りの取扱金融機関にご相談の上、必要書類を提出し、お申込みください。
2.  **金融機関による審査**: 取扱金融機関にて融資審査が行われます。
3.  **信用保証協会による保証審査**: 金融機関からの依頼に基づき、横浜市信用保証協会にて保証審査が行われます。
4.  **融資実行**: 金融機関および信用保証協会の審査を経て承認された場合、取扱金融機関より融資が実行されます。

※本制度のご利用にあたっては、取扱金融機関および横浜市信用保証協会の審査が必要です。記載内容は概要であり、融資実行・保証承諾をお約束するものではありません。
