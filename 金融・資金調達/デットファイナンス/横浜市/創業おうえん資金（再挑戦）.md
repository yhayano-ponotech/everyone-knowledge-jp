## 横浜市中小企業融資制度「[創業おうえん資金（再挑戦）](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/venture-retry.html)」のご案内

横浜市では、市内中小企業および小規模事業者の皆様の事業活動を支援するため、「横浜市中小企業融資制度」を提供しております。本稿では、過去に事業の廃止等を経験された方が横浜市内で再度創業に挑戦する場合を対象とした「創業おうえん資金（再挑戦）」について、その詳細をご案内いたします。

### 創業おうえん資金（再挑戦）とは

創業おうえん資金（再挑戦）は、過去に経営状況の悪化により事業を廃止、または会社を解散した経験を持つ方が、**横浜市内で新たに事業を開始**（または開始後5年未満）する際に、必要な運転資金および設備資金の調達を支援する融資制度です。再チャレンジを目指す起業家を後押しすることを目的としています。
本資金は、国の「再挑戦支援保証制度」の対象となります。

**※NPO法人の方は、本資金のご利用はできません。**

### 融資条件

創業おうえん資金（再挑戦）の主な融資条件は以下の通りです。

| 項目         | 内容                                                                 |
| :----------- | :------------------------------------------------------------------- |
| **融資対象者** | [横浜市中小企業融資制度の融資申込要件](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/yushi.html#moushikomi)を全て満たし、かつ以下の**追加要件**の全てを満たす中小企業者<br>1. 過去に自らが営んでいた事業を経営状況の悪化により**廃止**した経験を有する、又は過去に経営状況の悪化により**解散**した会社の当該解散の日において当該会社の業務を執行する役員であった<br>2. 事業の廃止日又は解散日から**5年未満**である<br>3. 横浜市内で**新たに事業を開始**する（又は新たな事業を開始してから**5年未満**である） |
| **資金使途**   | 運転資金及び設備資金                                                   |
| **融資額**     | 3,500万円以内                                                        |
| **利率（年利）** | 固定金利または変動金利から選択<br>**【固定金利】**<br>・3年以内： 年2.4％以内<br>・3年超5年以内： 年2.6％以内<br>・5年超10年以内： 年2.8％以内<br>**【変動金利】**<br>・短期プライムレート＋0.7％以内（＊）<br>*（＊）短期プライムレートは金融機関ごとに異なります。* |
| **融資期間**   | 運転資金：10年以内<br>設備資金：10年以内<br>（いずれも据置期間12か月以内を含む） |
| **担保**       | 原則として不要                                                       |
| **保証料率**   | **助成前**：年0.80％<br>**助成後**：年0.72％（横浜市が年0.08％助成）      |

### 必要書類

お申込みにあたっては、原則として以下の書類をご提出いただきます。

**【共通】**

1.  信用保証委託申込書（横浜市信用保証協会所定様式）
2.  申込人（個人・法人）及び連帯保証人（※1）の印鑑証明書（※2, 3）
3.  納税証明書（※2）、または領収書の写し、eLTAXや地方税お支払いサイトの納付済確認画面
4.  決算書（確定申告書）の写し（原則、直近2期分。創業前・創業後間もない場合は不要）
5.  【法人の場合】履歴事項全部証明書（商業登記簿謄本）または登記情報提供サービスで取得したもの（※2, 3。設立前は定款案等）
6.  許認可証等の写し（許認可等が必要な事業の場合）
7.  【設備資金の場合】見積書およびレイアウト・カタログ等の写し
8.  [創業・再挑戦計画書（創業関連保証・再挑戦支援保証用）【協会様式】](https://www.sinpo-yokohama.or.jp/guide/download/download-seidobetu/) （外部サイト）

*   ※1：連帯保証人が必要となる場合があります。
*   ※2：各種証明書は発行後3ヶ月以内の最新のものをご用意ください。納税証明書は[オンライン申請](https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/shizei-shomei/online/gaiyou.html)も可能です。
*   ※3：横浜市信用保証協会への申込時は写しでの提出が可能な場合があります。

**【市内で新たに事業を開始する場合の追加書類】**

*   市区町村が発行する「認定特定創業支援等事業により支援を受けたことの証明書」（写）（該当者のみ）

※上記以外の書類が必要になる場合があります。

### 融資実行までの流れ

融資実行までの標準的な手続きは以下の通りです。

1.  **ご相談・お申込み**: お取引のある、または最寄りの取扱金融機関にご相談の上、必要書類（創業・再挑戦計画書含む）を提出し、お申込みください。
2.  **金融機関による審査**: 取扱金融機関にて融資審査が行われます。
3.  **信用保証協会による保証審査**: 金融機関からの依頼に基づき、横浜市信用保証協会にて保証審査が行われます。
4.  **融資実行**: 金融機関および信用保証協会の審査を経て承認された場合、取扱金融機関より融資が実行されます。

※本制度のご利用にあたっては、取扱金融機関および横浜市信用保証協会の審査が必要です。記載内容は概要であり、融資実行・保証承諾をお約束するものではありません。
