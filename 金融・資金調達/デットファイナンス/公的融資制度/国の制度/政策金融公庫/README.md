# 日本政策金融公庫（JFC）

## 概要

日本政策金融公庫（Japan Finance Corporation、略称：JFC）は、国が100%出資する政策金融機関です。中小企業や個人事業主の資金調達を支援し、日本経済の発展に貢献することを目的としています。

## 事業区分

日本政策金融公庫は主に3つの事業で構成されています：

### 1. 国民生活事業

- **対象**: 小規模企業や個人事業主
- **特徴**: 
  - 小口融資が中心（平均融資額：約600万円）
  - 融資先はパン屋、飲食店、工務店など地域密着型の企業が多い
  - 約8割が無担保融資、約3割が無担保無保証での融資
  - 教育ローンなど個人向けの融資も実施

### 2. 中小企業事業

- **対象**: 一定規模の中小企業
- **特徴**:
  - 長期事業資金の融資が中心（平均融資額：約1億円）
  - 短期の運転資金は取り扱わない
  - 不動産などを担保にした融資が基本だが、必須ではない

### 3. 農林水産事業

- **対象**: 農林水産業者および食品産業事業者

## 主な融資制度

### 国民生活事業の主な融資制度

- **教育一般貸付（国の教育ローン）**
  - 対象：お子さまの教育資金を必要とする方
  - 融資限度額：350万円（一定の要件に該当する場合は増額可能）

- **経営環境変化対応資金**
  - 対象：売上が減少するなど業況が悪化している方
  - 融資限度額：4,800万円
  - 融資期間：設備資金15年以内、運転資金8年以内

- **金融環境変化対応資金**
  - 対象：取引金融機関の経営破たんなどにより資金繰りに困難を来している方
  - 融資限度額：別枠4,000万円

### 中小企業事業の主な融資制度

- **新たに事業を始める方向け融資**
  - 新規開業者、事業開始後おおむね7年以内の方向け
  - スタートアップ支援、経営革新計画承認者向け融資

- **企業活力強化貸付（企業活力強化資金）**
  - 対象：事業拡大・生産性向上等を図る場合
  - 融資限度額：無担保4,800万円、有担保7,200万円
  - 返済期間：設備資金20年以内、運転資金7年以内

## 融資を受けるまでの流れ

1. 支店に借入申込書を提出（またはインターネットから申し込み）
2. 必要書類の準備
3. 担当者との面談
4. 審査結果の通知
5. 指定口座への借入金入金

## 政策金融公庫の融資メリット

- 創業初期でも融資の審査が通りやすい
- 無担保・無保証人で利用できる融資制度がある
- 条件によっては民間金融機関より金利が低いこともある
- 返済期間が長めに設定されている

## 新規創業者向け特別制度

新規開業・スタートアップ支援資金では、以下の方々に対する特別な支援があります：

1. 女性、35歳未満または55歳以上の方
2. 外国人起業活動促進事業における特定外国人起業家の方
3. 新たに事業を始める方

新創業融資制度は、「新たに事業を始める方や事業を開始して間もない事業者を対象とした無担保・無保証人で利用できる制度」です。事業開始後でも利用可能な場合があります。
