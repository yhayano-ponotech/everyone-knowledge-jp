# [IT活用促進資金](https://www.jfc.go.jp/n/finance/search/11_itsikin_m_t.html)

情報技術の普及・変化に関連した事業環境の変化に対応するための情報技術の活用の促進を図る中小企業者を支援します。

詳しくは、支店の窓口までお問い合わせください。

## IT活用促進資金の概要

| 項目 | 内容 |
|-----|------|
| ご利用いただける方 | 次のいずれかに当てはまる方<br>1. 情報技術（IT）の普及に伴う事業環境の変化に対応するための情報化投資を行う方で、次のいずれかに当てはまる方<br>　A. 情報技術（IT）を活用した効果的な企業内業務改善および企業内の情報交換など業務の高度化を行う方<br>　B. 他企業、消費者などとの間でネットワーク上の取引および情報の受発信を行う方<br>　C. 企業内業務の情報技術（IT）の水準を取引先など企業外の情報技術（IT）の水準に合わせようとする方<br>　D. 情報技術（IT）の活用により、業務方法、業務内容などの経営革新を図ろうとする方<br>　E. A～Dを組み合わせるなど、情報技術（IT）などを高度に活用する方<br>2. 中小企業等経営強化法に基づき認定を受けた情報処理支援機関<br>3. 特定高度情報通信技術活用システムの開発供給および導入の促進に関する法律に基づく特定高度情報通信技術活用システム開発供給計画の認定を受けた方または特定高度情報通信技術活用システム導入計画の認定を受けた方<br>4. 特定高度情報通信技術活用システムの開発供給及び導入の促進に関する法律に基づく特定半導体生産施設整備等計画の認定（変更認定を含む。）を受けた方<br>5. テレワークの導入等を行う方 |
| 資金のお使いみち | 「ご利用いただける方」1または5の方<br>次の設備を取得するための設備資金および長期運転資金<br>・電子計算機（ソフトウェアを含みます。）（※）<br>・周辺装置（電子計算機本体と組み合わせて使用するモデムなどの通信装置など）<br>・端末装置（多機能情報端末など）<br>・被制御設備：高度数値制御加工装置（CNC）、多軸産業用ロボット装置など<br>・関連設備：LANケーブルやゲートウェイ装置など<br>・関連建物・構築物（上記装置、設備の導入と併せてその取得に必要不可欠なもの）<br><br>「ご利用いただける方」2の方<br>中小企業等経営強化法に定める情報処理支援業務を行うために必要な設備資金（ソフトウェア含む）および長期運転資金<br><br>「ご利用いただける方」3の方<br>認定開発供給計画または認定導入計画を実施するために必要とする設備資金(土地にかかる資金を除く。)および長期運転資金<br><br>「ご利用いただける方」4の方<br>認定特定半導体生産施設整備等計画を実施するために必要とする設備資金および長期運転資金<br><br>「ご利用いただける方」1～5の方の長期運転資金には以下のものを含みます。<br>・設備などを賃借するために必要な資金<br>・ソフトウェアの取得、制作および運用に必要な資金など<br>・建物等の更新に伴い一時的に施設等を賃借するために必要な資金<br><br>（※）「電子計算機」については、単体で導入する場合はご融資の対象となりません。（1～5の設備との連携を図るために導入する場合などにご融資の対象となります。） |
| 融資限度額 | 直接貸付 7億2千万円<br>代理貸付 1億2千万円 |
| 利率（年） | 設備資金<br>「ご利用いただける方」1の方<br>[基準利率](#基準利率)。<br>ただし、次の要件を満たす場合は、それぞれに定める利率<br>（A）DX推進指標を活用し、その診断結果を経済産業省が指定する方法で同省が指定する機関に提出している方については、2億7千万円まで基準利率－0.2％<br>（B）中小企業等経営強化法の規定に基づき認定を受けた情報処理支援機関または情報処理の促進に関する法律に基づくDX認定制度の認定（効力を有する認定に限る。）を受けている方については、2億7千万円まで[特別利率②](#特別利率②)<br>（C）産業競争力強化法の規定に基づき認定を受けた技術等情報漏えい防止措置認証機関から、技術及びこれに関する研究開発の成果、生産方法その他の事業活動に有用な情報の漏えいを防止するために必要な措置に関する基準に基づく認証を受けた方が必要とする設備資金については、2億7千万円まで[特別利率①](#特別利率①)<br><br>「ご利用いただける方」2の方<br>2億7千万円まで [特別利率②](#特別利率②)<br>2億7千万円超 [基準利率](#基準利率)<br><br>「ご利用いただける方」3の方<br>2億7千万円まで [特別利率③](#特別利率③)<br>2億7千万円超 [基準利率](#基準利率)<br><br>「ご利用いただける方」4の方<br>2億7千万円まで(土地にかかる資金を除く) [特別利率③](#特別利率③)<br>2億7千万円超 [基準利率](#基準利率)<br><br>「ご利用いただける方」5の方<br>2億7千万円まで [特別利率①](#特別利率①)<br>2億7千万円超 [基準利率](#基準利率)<br><br>※なお、信用リスク・融資期間などに応じて所定の利率が適用されます。ただし、ご利用いただける方の1、2または5の方であって、資金のお使いみちが無形固定資産または繰延資産に計上される資産の場合で、担保を徴しない場合には、利率の引き下げ措置があります。 |
| ご返済期間 | 設備資金 20年以内（うち据置期間2年以内）<br>運転資金 7年以内（うち据置期間2年以内） |
| 担保・保証人等 | ・担保設定の有無、担保の種類などについては、ご相談のうえ決めさせていただきます。<br>・直接貸付において、一定の要件に該当する場合には、経営責任者の方の個人保証が必要となります。 |
| 融資のお申込み | 直接貸付 日本公庫各支店の中小企業事業の窓口にお申し込みください。<br>代理貸付 日本公庫中小企業事業の代理店の窓口にお申し込みください。 |
