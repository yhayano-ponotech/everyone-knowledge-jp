# [シンジケートローン特別貸付](https://www.jfc.go.jp/n/finance/search/syndicate.html)

新規事業、環境対策、経営改善などに取り組む方へ民間金融機関と連携して資金を供給する制度です。

詳しくは、支店の窓口までお問い合わせください。

## シンジケートローン特別貸付の概要

| 項目 | 内容 |
|-----|------|
| ご利用いただける方 | 新規事業、環境対策、経営改善などに取り組む方（注）であって、地域経済の維持・促進に資する事業に取り組む方<br><br>（注）新企業育成貸付、企業活力強化貸付、環境・エネルギー対策貸付または企業再生貸付の適用要件を満たす方（セーフティネット貸付制度、新型コロナウイルス感染症特別貸付制度などを除く。） |
| 資金のお使いみち | 各特別貸付に定める設備資金および長期運転資金 |
| 融資限度額 | 直接貸付 1社あたり原則として14億4千万円 |
| 利率（年） | シンジケートローンに参加する金融機関が[合意した利率](#金利情報)（ただし、固定利率の場合は、一定の制約有） |
| ご返済期間 | シンジケートローンに参加する金融機関が合意した期間（ただし、設備資金は30年以内、運転資金は20年以内に限る。） |
| ご返済方法 | シンジケートローンに参加する金融機関が合意した方法（ただし、割賦期間については、1、2、3、6、12ヵ月のいずれかに限る。） |

## <a name="金利情報"></a>金利情報（令和7年5月1日現在）

シンジケートローン特別貸付の金利は、参加する金融機関間の合意によって決定されます。具体的な金利は各金融機関および案件の特性により異なりますので、詳細については最寄りの支店窓口にお問い合わせください。

基本的には、以下の要素を考慮して金利が設定されます：

- 融資期間
- 担保の有無
- 事業の性質と信用リスク
- 市場金利の動向
- 参加金融機関の融資方針

固定金利を選択する場合は、一定の制約があります。変動金利と固定金利の詳細な条件については、個別にご相談ください。
