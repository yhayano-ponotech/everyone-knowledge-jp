# [公庫融資借換特例制度](https://www.jfc.go.jp/n/finance/search/58.html)

社会的、経済的環境の変化など外的要因や金融機関との取引状況の変化により資金繰りに困難を来している方、経営改善、経営再建などに取り組む必要が生じている方および弁済に係る負担の軽減を必要としている方が、経営安定や中小企業者の自助努力による企業再建の支援を図るために、既往公庫融資の借換などを行う制度です。

詳しくは、支店の窓口までお問い合わせください。

## 公庫融資借換特例制度の概要

| 項目 | 内容 |
|-----|------|
| ご利用いただける方 | セーフティネット貸付制度の経営環境変化対応資金および金融環境変化対応資金、東日本大震災復興特別貸付、令和2年7月豪雨特別貸付、令和6年能登半島地震特別貸付、企業再生貸付制度の事業再生・企業再建支援資金（一部の対象を除く）、企業活力強化貸付制度の事業承継・集約・活性化支援資金、挑戦支援資本強化特別貸付または危機対応後経営安定貸付制度による貸付けを受ける方。<br><br>原則として、既往の公庫融資の借換のほか、新規融資をご利用いただく必要があります。 |
| 融資限度額 | 適用した特別貸付制度（経営環境変化対応資金、金融環境変化対応資金、東日本大震災復興特別貸付、令和2年7月豪雨特別貸付、令和6年能登半島地震特別貸付、事業再生・企業再建支援資金、事業承継・集約・活性化支援資金、挑戦支援資本強化特別貸付または危機対応後経営安定貸付制度）の貸付限度額 |
| 利率（年） | 適用した特別貸付制度に定める[利率](#利率一覧表)<br><br>ただし、借換部分のうち、次の要件に当てはまる場合は、それぞれに定める利率（挑戦支援資本強化特別貸付を除く。）<br><br>借換対象の貸付口の加重平均金利（注）がご融資時の[基準利率](#基準利率)を上回る場合は、加重平均金利を適用します。<br><br>一定の要件に該当する場合は、適用利率をもとに計算した加重平均金利、適用した特別貸付制度の上限金利や貸付利率の控除が適用されます。<br><br>（注）金銭消費貸借契約証書上の利率をもとに計算(平成23年4月1日以降は条件違反時利率)。 |
| ご返済期間 | **経営環境変化対応資金<br>金融環境変化対応資金**<br>8年以内(うち据置期間原則1ヶ月以内)<br><br>**事業再生・企業再建支援資金**<br>20年以内（うち据置期間原則1ヶ月以内)<br><br>**事業承継・集約・活性化支援資金**<br>10年以内（うち据置期間原則1ヶ月以内)<br><br>**挑戦支援資本強化特別貸付制度**<br>5年1か月または6年から20年までの各年(期限一括償還)<br><br>**危機対応後経営安定貸付制度**<br>20年（うち据置期間原則1カ月以内)<br><br>**東日本大震災復興特別貸付**<br>8年以内(うち据置期間原則1ヶ月以内)<br>一定の要件に該当する場合は、15年以内（うち据置期間原則1ヶ月以内)<br><br>**令和2年7月豪雨特別貸付**<br>15年以内（うち据置期間原則1ヶ月以内)<br><br>**令和6年能登半島地震特別貸付**<br>15年以内（うち据置期間原則1ヶ月以内) |
| その他 | ・既往の融資については一部借換の対象にできないものもあります。<br>・借換部分に対する融資金額は、借換対象口ごとに10万円未満の端数を切り捨てた金額となります。<br>・挑戦支援資本強化特別貸付で借換のみを希望される方は、日本公庫中小企業事業の窓口にご相談ください。<br>・上記以外の貸付条件は、各特別貸付で定められています。 |
| 本（特例）制度のお申込み | 直接貸付<br>日本公庫各支店の中小企業事業の窓口にお申し込みください。 |

※本制度の利用には、事業の見通しなどについて、審査が必要になります。審査の結果、本制度をご利用いただけない場合もあります。
