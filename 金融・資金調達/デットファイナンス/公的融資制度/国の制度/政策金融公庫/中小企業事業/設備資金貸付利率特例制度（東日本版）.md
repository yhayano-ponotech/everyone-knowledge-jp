# [設備資金貸付利率特例制度（東日本版）](https://www.jfc.go.jp/n/finance/search/setsubishikin_t.html)

東日本大震災からの再建復興を図るため、長期の設備投資を行う方に対して、金利負担を軽減することにより投資を促進することを目的とする制度です。

詳しくは、支店の窓口までお問い合わせください。

## 設備資金貸付利率特例制度（東日本版）の概要

| 項目 | 内容 |
|-----|------|
| ご利用いただける方 | 特別貸付制度（注）による設備資金であって、福島復興再生特別措置法に定める避難指示・解除区域が所在した市町村において雇用の維持または雇用の拡大が見込まれる設備資金をご利用される方<br>（注）一部ご利用いただけない制度もあります |
| 融資限度額 | 適用する特別貸付制度の融資限度額 |
| 適用利率<br>適用期間 | 適用する特別貸付制度に定める[利率](#利率情報)からご融資期間中0.5％を控除します。<br>（※）利率の下限は0.3％（一部制度は0.05％） |
| その他 | 事業の用に使用されない土地の取得については本制度の対象にできません。<br>上記以外の融資条件は、各特別貸付制度で定められています。 |

## <a name="利率情報"></a>利率情報（令和7年5月1日現在）

本制度は、適用する特別貸付制度の利率から0.5%を控除する制度です。基本となる貸付制度には、以下のような利率体系があります。

### 基準利率（標準的な特別貸付制度の場合）

| 貸付期間 | 基準利率 | 適用利率（0.5%控除後） |
|---------|----------|------------------------|
| 5年以内 | 1.75% | 1.25% |
| 5年超 10年以内 | 1.85%～2.05% | 1.35%～1.55% |
| 10年超 15年以内 | 2.05%～2.35% | 1.55%～1.85% |
| 15年超 20年以内 | 2.45%～2.65% | 1.95%～2.15% |

※利率の下限は0.3%（一部制度は0.05%）となります。
※上記は標準的な利率例です。実際の適用利率は、ご利用される特別貸付制度の種類、返済期間、担保の有無などにより異なりますので、詳しくは最寄りの支店窓口にお問い合わせください。
