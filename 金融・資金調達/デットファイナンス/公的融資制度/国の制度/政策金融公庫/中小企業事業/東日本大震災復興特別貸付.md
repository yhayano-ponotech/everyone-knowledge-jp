# [東日本大震災復興特別貸付](https://www.jfc.go.jp/n/finance/search/shinsaikashitsuke_t.html)

東日本大震災により被害を受けた中小企業者および東日本大震災に起因する影響を受けた中小企業者の事業の復旧を促進し、被災地域などの復興を支援します。

詳しくは、支店の窓口までお問い合わせください。

## 東日本大震災復興特別貸付の概要

| 項目 | 内容 |
|-----|------|
| ご利用いただける方 | 次のいずれかに当てはまる方<br>1. 岩手県及び宮城県のうち、東日本大震災復興特別区域法施行令に定める東日本大震災からの復興に向けた取組を重点的に推進する必要があると認められる区域、または福島県に事業所を有し事業活動を行う方であり、かつ、東日本大震災の地震・津波により直接の被害を受けた方<br>2. 原子力発電所の事故に係る警戒区域、計画的避難区域および緊急時避難準備区域内に事務所を有し事業活動を行う方<br>3. 福島県に事業所を有し事業活動を行う方であり、かつ、1または2に掲げる方（大企業を含む）と取引があり、間接的に被害を受けた方<br>4. 福島県に事業所を有し事業活動を行う方であり、かつ、東日本大震災に起因する社会的な要因（風評被害、計画停電等）による一時的な業況悪化により資金繰りに支障を来している、または来すおそれがあり、中長期的には業況の回復が見込まれる方 |
| 資金のお使いみち | 災害復旧及び災害に伴う社会的要因等により必要とする設備資金および長期運転資金<br>長期運転資金には、建物等の更新に伴い一時的に施設等を賃借するために必要な資金を含みます。 |
| 融資限度額 | 「ご利用いただける方」1～3の方：直接貸付　3億円、代理貸付　7.5千万円<br>「ご利用いただける方」4の方：直接貸付　7.2億円 |
| 利率（年） | 「ご利用いただける方」1、2の方：[基準利率](#基準利率)<br>ただし、被害証明書を市町村長などから受けた方は、<br>・1億円を限度として、融資後3年目までは[基準利率](#基準利率)-1.4％、4年目以降は[基準利率](#基準利率)-0.5％<br>・3億円を限度として、[基準利率](#基準利率)-0.5％<br><br>「ご利用いただける方」3の方：[基準利率](#基準利率)<br>ただし、被害証明書を市町村長などから受けた方（※）は、<br>・3千万円を限度として、[基準利率](#基準利率)-0.9％、4年目以降は[基準利率](#基準利率)<br>・一定の要件（注）に該当する場合は、所定の貸付利率（0.2％、0.3％または0.5％）が控除されます<br><br>「ご利用いただける方」4の方：[基準利率](#基準利率)（長期運転資金に限り、上限3％）<br>ただし、一定の要件（注）に該当する場合は、所定の貸付利率（0.2％、0.3％または0.5％）が控除されます。<br>※なお、信用リスク・融資期間などに応じて所定の利率が適用されます。<br><br>（注）<br>（イ）最近3カ月の売上高、売上高総利益率または売上高営業利益率が前15年のいずれかの年の同期に比し5％以上減少している場合、または最近1カ月の売上高、売上高総利益率または売上高営業利益率が前15年のいずれかの年の同月に比し20％以上減少しており、かつ、その後2カ月を含む3カ月の売上高、売上高総利益率または売上高営業利益率が前15年のいずれかの年の同期に比し20％減少することが見込まれる場合は、0.3％控除<br>（ロ）雇用維持または雇用の拡大を図る場合は、0.2％控除<br>（ハ）（イ）及び（ロ）のいずれの要件にも該当する場合は、0.5％控除 |
| ご返済期間 | 1. 「ご利用いただける方」1、2：設備資金 20年以内（うち据置期間5年以内）、運転資金 15年以内（うち据置期間5年以内）<br>2. 「ご利用いただける方」3：設備資金 20年以内（うち据置期間3年以内）、運転資金 15年以内（うち据置期間3年以内）<br>3. 「ご利用いただける方」4：設備資金 15年以内（うち据置期間3年以内）、運転資金 8年以内（うち据置期間3年以内） |
| 担保・保証人等 | ・担保設定の有無、担保の種類などについては、ご相談のうえ決めさせていただきます。<br>・直接貸付において、一定の要件に該当する場合には、経営責任者の方の個人保証が必要となります。 |
| 融資のお申込み | 直接貸付　日本公庫各支店の中小企業事業の窓口にお申し込みください。<br>代理貸付　日本公庫中小企業事業の代理店の窓口にお申し込みください。 |
