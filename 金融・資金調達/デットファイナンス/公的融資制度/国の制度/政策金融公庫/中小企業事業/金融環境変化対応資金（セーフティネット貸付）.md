# [金融環境変化対応資金（セーフティネット貸付）](https://www.jfc.go.jp/n/finance/search/05_kinyuukankyou_m_t.html)

金融機関との取引状況の変化により、資金繰りに困難を来している中小企業者の経営安定を支援します。

詳しくは、支店の窓口までお問い合わせください。

## 金融環境変化対応資金の概要

| 項目 | 内容 |
|-----|------|
| ご利用いただける方 | 金融機関との取引状況の変化により、一時的に資金繰りに困難を来し、中長期的には資金繰りが改善し経営が安定することが見込まれる方であって、次のいずれかに該当する方。<br>・取引金融機関が行政庁から業務停止命令（一部業務停止命令を含む。）を受けた方<br>・取引金融機関が実質的に経営破綻の状態等にある方<br>・預金保険法等の規定に基づき、取引金融機関からの借入等が株式会社整理回収機構に譲渡された方などで、経常利益を計上しているなど、業況が順調であると認められる方<br>・経営状況が悪化していないにもかかわらず、金融機関からの借入金利が長期プライムレートの変動に比べ相対的に上昇するなどの状況にある方<br>・国際的な金融不安や経済環境の変化を背景に、取引金融機関から次の（1）から（5）までのいずれかの要請または取扱いを受けている方<br>　（1）借入残高の減少<br>　（2）約定した返済条件を超える弁済<br>　（3）当座預金の解約<br>　（4）担保・保証人の追加<br>　（5）借入金利の引上げ |
| 資金のお使いみち | 設備資金および金融機関との取引状況の変化に伴い必要となる長期運転資金<br>長期運転資金には、建物等の更新に伴い一時的に施設等を賃借するために必要な資金を含みます。<br>（「ご利用いただける方3」に該当する方が株式会社整理回収機構に対して繰上返済を行うために必要な資金を含む） |
| 融資限度額 | 直接貸付 3億円 |
| 利率（年） | [基準利率](#基準利率)（長期運転資金に限り、上限2.5％）<br>※なお、信用リスク・融資期間などに応じて所定の利率が適用されます。 |
| ご返済期間 | 設備資金：15年以内（うち据置期間3年以内）<br>運転資金：8年以内（うち据置期間3年以内） |
| 担保・保証人等 | ・担保設定の有無、担保の種類などについては、ご相談のうえ決めさせていただきます。<br>・直接貸付において、一定の要件に該当する場合には、経営責任者の方の個人保証が必要となります。 |
| 融資のお申込み | 直接貸付 日本公庫各支店の中小企業事業の窓口にお申し込みください。 |
