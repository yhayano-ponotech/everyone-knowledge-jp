# [危機対応後経営安定貸付](https://www.jfc.go.jp/n/finance/search/keieiantei_t.html)

過去の大規模な災害、感染症等の影響を受け、既往債務の返済負担が生じている中小企業者であって、中長期的には、その業況が回復し、かつ、発展することが見込まれる方を支援します。

詳しくは、支店の窓口までお問い合わせください。

## 危機対応後経営安定貸付の概要

| 項目 | 内容 |
|-----|------|
| ご利用いただける方 | 過去の大規模な災害、感染症等の影響を受け、次のすべての要件を満たす方<br><br>（1）次のいずれかの貸付制度に係る貸付残高を有すること<br>①新型コロナウイルス感染症特別貸付<br>②新型コロナウイルス感染症対策挑戦支援資本強化特別貸付<br>③危機対応後経営安定貸付<br><br>（2）債務負担が重くなっていること（注）<br><br>（3）中長期的にみて、業況が回復し、かつ、発展することが見込まれること |
| 資金のお使いみち(※) | 既往債務の返済負担軽減のために必要とする長期運転資金<br><br>※長期運転資金には、建物等の更新に伴い一時的に施設等を賃借するために必要な資金を含みます。 |
| 融資限度額 | 直接貸付 20億円<br>代理貸付 2億2千5百万円 |
| 利率（年） | [基準利率](#基準利率) |
| ご返済期間 | 運転資金 20年以内（うち据置期間2年以内） |
| 担保・保証人等 | ・担保設定の有無、担保の種類などについては、ご相談のうえ決めさせていただきます。<br>・直接貸付において、一定の要件に該当する場合には、経営責任者の方の個人保証が必要となります。 |
| 融資のお申込み | 直接貸付 日本公庫各支店の中小企業事業の窓口にお申し込みください。<br>代理貸付 日本公庫中小企業事業の代理店の窓口にお申し込みください。 |

（注）一定の要件を満たす必要があります。詳しくは日本公庫中小企業事業の窓口にお問い合わせください。
