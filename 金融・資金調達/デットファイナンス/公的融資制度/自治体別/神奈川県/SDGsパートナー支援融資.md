## 神奈川県 制度融資「[SDGsパートナー支援融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/sdgs_shien.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**SDGs（持続可能な開発目標）の達成に貢献する取組**を行う事業者の皆様を対象とした「SDGsパートナー支援融資」について、その詳細をご案内いたします。

*   [チラシはこちら（PDF）](https://www.pref.kanagawa.jp/documents/52087/r7_sdgspartner.pdf)

### ご利用いただける方

以下のいずれかに該当する方が対象となります。

*   ア：[**かながわSDGsパートナー**](https://www.pref.kanagawa.jp/docs/bs5/sdgs/partner.html)に登録している[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)（NPO法人を含む）及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)
*   イ：上記アに該当する方のうち、**SDGsの取組に関する事業計画**を策定し、計画を実行する[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)（NPO法人を含む）及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)

（参考）[かながわSDGsパートナー制度について](https://www.pref.kanagawa.jp/docs/bs5/sdgs/partner.html)

### 融資条件

SDGsパートナー支援融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                           |
| :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金                                                                                                                               |
| **融資限度額**       | **【アの場合】2,000万円**<br>**【イの場合】4,000万円**<br>※アにより融資を受けた方がイにより融資を受ける場合、**合計4,000万円**まで                             |
| **融資利率（固定）** | **【アの場合】年2.0%以内**<br>**【イの場合】年1.8%以内**                                                                                             |
| **融資期間**         | 運転資金：1年超10年以内<br>設備資金：1年超15年以内                                                                                                  |
| **返済方法**         | 分割返済（1年以内の据置き可）                                                                                                                    |
| **担保**             | 必要に応じて                                                                                                                                 |
| **保証人**           | 原則として**法人の代表者は連帯保証人となります**                                                                                                     |
| **信用保証料率**     | **年0.35%～1.42%** （※神奈川県による補助及び神奈川県信用保証協会の割引後の料率です。国のSDGs・地域活性化応援保証が適用されます） |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html?mode=preview#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   **かながわSDGsパートナー登録証の写し**
*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【対象者イの場合】**

*   【様式15】政策連動資金（SDGsパートナー支援融資）事業計画書

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
