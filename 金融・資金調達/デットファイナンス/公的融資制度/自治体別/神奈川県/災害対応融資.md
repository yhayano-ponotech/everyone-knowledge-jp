## 神奈川県 制度融資「[災害対応融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/saigaitaiou_yusi.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**自然災害等により被害を受けた**事業者の皆様を対象とした「災害対応融資」について、その詳細をご案内いたします。

（※令和6年台風第10号に伴う被害等にもご利用いただけます。）

*   [チラシはこちら（PDF）](https://www.pref.kanagawa.jp/documents/112134/r7_saigaitaiou_tirasi.pdf)

### ご利用いただける方

以下のいずれかに該当する[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)が対象となります。

*   ア：自然災害等により**設備等の破損・遺失等被害**を受けた方（**一般枠**）
*   イ：自然災害等に起因して、**セーフティネット保証4号に基づく市町村長の認定**を受けた方（**別枠**）
*   ウ：**激甚災害指定された自然災害等**により設備等の破損・遺失等の被害を受けた方（**激甚災害枠**）

### 融資条件

災害対応融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                                                                |
| :------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金 （注記1）                                                                                                                                                           |
| **融資限度額**       | **【ア】2億8,000万円**<br>**【イ】2億8,000万円（別枠）**<br>**【ウ】2億8,000万円**                                                                                                              |
| **融資利率（固定）** | ・2年以内： **年1.3％以内**<br>・2年超5年以内： **年1.6％以内**<br>・5年超15年以内： **年1.9％以内**                                                                                             |
| **融資期間**         | 運転資金：10年以内<br>設備資金：15年以内                                                                                                                                              |
| **返済方法**         | 分割返済（**2年以内**の据置き可）<br>※融資期間1年以内の場合は一括返済も可                                                                                                                 |
| **担保**             | 必要に応じて                                                                                                                                                                      |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                                                                                            |
| **信用保証料率**     | **【ア】年0.26%～1.42%** （注記2）<br>**【イ】年1.00％** （**令和6年台風第10号関連は0.60％** 注記2、注記3）<br>**【ウ】年1.00％**<br>※国の災害関係保証制度が適用されます（信用保証協会による審査あり）。 |

*   注記1：アまたはウに該当する場合は事業の再建に、イに該当する場合は経営の安定に必要な資金に限ります。
*   注記2：県の補助及び神奈川県信用保証協会の割引後の料率です。
*   注記3：令和6年台風第10号に係るものに限ります。（SN4号の認定書の申請期間は終了しています）

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【対象者アの場合】**

*   市町村等が発行する罹災届出証明書等

**【対象者イの場合】**

*   事業所の所在する市町村長の認定書（セーフティネット保証4号）

**【対象者ウの場合】**

*   市町村等が発行する罹災証明書等

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
