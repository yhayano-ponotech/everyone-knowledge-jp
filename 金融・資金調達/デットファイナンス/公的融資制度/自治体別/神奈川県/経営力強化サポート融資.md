## 神奈川県 制度融資「[経営力強化サポート融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/keieiryoku_kyouka.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**認定経営革新等支援機関**のサポートを受けながら**経営改善に取り組む**事業者の皆様を対象とした「経営力強化サポート融資」について、その詳細をご案内いたします。

### ご利用いただける方

以下のいずれかに該当する[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)が対象となります。

*   ア：**取扱金融機関**及び**認定経営革新等支援機関**の支援を受けつつ、自ら**事業計画**の策定並びに計画の実行及び進捗の報告を行う方
*   イ：上記アに加え、**セーフティネット保証5号の認定**を受け、国の定める**新型コロナウィルス感染症関連保証に係る既往借入金を借り換える**方

### 融資条件

経営力強化サポート融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                                   |
| :------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金<br>（アの場合は事業計画の実施に必要な資金、イの場合は借換資金に限ります）                                                                         |
| **融資限度額**       | 8,000万円（※一部、通常の保証限度額とは別枠扱いとなります）                                                                                                        |
| **融資利率（固定）** | **年2.0%以内**                                                                                                                                           |
| **融資期間**         | **【ア（事業計画実施）】** 運転資金：5年以内、設備資金：7年以内<br>**【イ（借換）】** 10年以内                                                                          |
| **返済方法**         | 分割返済（1年以内の据置き可）<br>※融資期間1年以内の場合は一括返済も可                                                                                                   |
| **担保**             | 必要に応じて                                                                                                                                           |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                                                               |
| **信用保証料率**     | **【ア（事業計画実施）】年0.45%～1.75%**<br>**【イ（借換）】年0.85%**<br>※本融資に対する県の信用保証料補助はありません。国の経営力強化保証制度が適用されます。 |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html?mode=preview#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）
*   国の定める「経営力強化保証」申込人資格要件等届出書
*   国の定める事業計画書（申込人が策定したもの）
*   **（イの場合）** 事業所の所在する市町村長の認定書（セーフティネット保証5号）

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
