## 神奈川県 制度融資「[創業支援融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p848390.html)」のご案内

神奈川県では、県内で新たに事業を開始される方や、創業後間もない中小企業の皆様を資金面から支援するため、「創業支援融資」制度を提供しております。本稿では、当制度の詳細についてご案内いたします。

### ご利用いただける方

以下のいずれかに該当する方が対象となります。

*   ア：事業を行っていない個人で、1か月以内に県内で**個人事業**を創業予定の方
*   イ：事業を行っていない個人で、2か月以内に県内で**法人を設立**し創業予定の方
*   ウ：**分社化**により別法人を設立して法人事業を創業予定の中小企業者
*   エ：事業を行っていない個人が**個人事業を創業してから5年未満**の方
*   オ：事業を行っていない個人が**法人を設立してから5年未満**の中小企業者
*   カ：**分社化**により設立された法人で、設立してから5年未満の中小企業者
*   キ：事業を行っていない個人が開始した事業を**法人化**し、個人事業創業時から5年未満の中小企業者
*   ク：経営状況の悪化により事業を廃止又は法人を解散してから5年未満で、上記**ア・イ・エ・オ・キ**のいずれかに該当する方（**再挑戦者**）

### 創業特例（融資利率の優遇）

上記アからクに該当する方のうち、以下のいずれかの要件を満たす場合は、**融資利率の優遇（創業特例）**が適用されます。

1.  融資申込み前に**創業支援機関**（公益財団法人神奈川産業振興センター、商工会、商工会議所等）の経営指導を受け、かつ、融資実行後も概ね2回以上の経営指導を受ける方
2.  国が認定した市町村の**特定創業支援等事業**を利用した方（創業前の場合は創業の6か月前から利用可）
    *   **神奈川県内の実施市町村（令和7年4月15日現在）**: 横浜市、川崎市、相模原市、横須賀市、平塚市、鎌倉市、藤沢市、小田原市、茅ヶ崎市、逗子市、三浦市、秦野市、厚木市、大和市、伊勢原市、海老名市、座間市、南足柄市、綾瀬市、葉山町、二宮町、寒川町、松田町、山北町、箱根町、真鶴町、愛川町・清川村 （各市町村のリンクは省略）

### 経営者保証について

以下の要件を満たした**法人**は、**経営者の個人保証が不要**となります。

1.  融資申込受付時点で税務申告1期未満の場合は、**創業資金総額の10分の1以上の自己資金**を有すること。
2.  所定の**創業計画書**を提出すること。
3.  創業3年目と5年目に専門家による**経営者保証ガイドラインの充足状況の確認と助言**を受けること。

### 融資条件

創業支援融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目           | 内容                                                                                                                                   |
| :------------- | :------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**     | 運転資金・設備資金                                                                                                                       |
| **融資限度額**   | 3,500万円                                                                                                                                |
| **融資利率（固定）** | **【通常】年2.0%以内**<br>**【創業特例 適用時】年1.8%以内**                                                                                     |
| **融資期間**     | 1年超10年以内                                                                                                                            |
| **返済方法**     | 分割返済（1年以内の据置き可 ※注1）                                                                                                         |
| **担保**         | 不要                                                                                                                                   |
| **保証人**       | 原則として法人代表者以外の連帯保証人は不要<br>※上記「経営者保証について」の要件を満たす法人は、経営者保証も不要                                               |
| **信用保証料率** | **【通常】年0.40%** （経営者保証不要の場合 **年0.60%**）<br>**【創業特例 適用時】年0.00%** （経営者保証不要の場合 **年0.20%**）<br>※県の補助及び神奈川県信用保証協会の割引後の料率 |

*   注記1：経営者保証を不要とする要件を満たし、申込金融機関においてプロパー融資残高があるか、本融資と同時にプロパー融資を実行する場合、据置期間は**3年以内**となります。
*   注記2：信用保証料率は、県の補助及び神奈川県信用保証協会の割引を適用した後の料率です。

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   客観的に事業を開始したことを証する書類の写し（例：創業後の個人事業者は、個人事業開業届出書の写し）

**【状況に応じた追加書類】**

*   **（創業前、創業後1年未満又は上記ク（再挑戦者）の場合）**
    *   【様式5-1】創業・再挑戦計画書
*   **（上記ク（再挑戦者）の場合）**
    *   [資格要件申告書](https://www.pref.kanagawa.jp/documents/10454/sikakuyoukensinkokusho.xlsx) (Excelファイル)
*   **（経営者保証不要の要件を満たす場合）**
    *   [創業計画書](https://www.pref.kanagawa.jp/documents/10454/sss_keikakusyo.xls) (Excelファイル)
*   **（創業特例(1) 創業支援機関の指導を受ける場合）**
    *   【様式5-3】「ライフステージ別資金（創業期）」創業支援融資【創業特例】確認（申請）書
*   **（創業特例(2) 特定創業支援等事業を利用した場合）**
    *   特定創業支援等事業により支援を受けたことについての市町村長の証明書の写し

**【決算を迎えている場合】**

*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し
