## 神奈川県 制度融資「[流動資産担保融資（ABL）](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p845778.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、事業者が保有する**売掛債権**や**棚卸資産（在庫）**を担保として活用できる「流動資産担保融資」について、その詳細をご案内いたします。

### ご利用いただける方

*   **売掛債権**または**棚卸資産**を保有する[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)

### 融資条件

流動資産担保融資の主な融資条件は以下の通りです。本融資は神奈川県信用保証協会の**信用保証付き**となります。

| 項目           | 内容                                                                                              |
| :------------- | :------------------------------------------------------------------------------------------------ |
| **資金使途**     | 運転資金・設備資金                                                                                  |
| **融資限度額**   | 2億5,000万円                                                                                        |
| **融資利率**     | 金融機関所定金利（固定金利・変動金利）                                                              |
| **融資期間**     | 1年以内                                                                                           |
| **返済方法**     | **個別保証の場合**: 一括返済<br>**根保証の場合**: 約定弁済又は随時弁済                                        |
| **担保**         | **売掛債権** または **棚卸資産**                                                                    |
| **保証人**       | 原則として法人の代表者以外の連帯保証人は不要                                                          |
| **信用保証料率** | **年0.34%** （※神奈川県による補助後の料率です）                                                     |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）
*   担保に提供する売掛債権又は棚卸資産の内容の分かる資料

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
