## 神奈川県 制度融資「[輸出入促進資金](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p848238.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**輸出入を行う貿易関連業者**や**直接輸入業務を行う卸・小売業者**の皆様を対象とした「輸出入促進資金」について、その詳細をご案内いたします。

### ご利用いただける方

*   貿易関連業者（輸出入商社または輸出品製造業者）
*   直接輸入業務を行う卸・小売業を営む方

※上記に該当する[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)が対象です。

### 融資条件

輸出入促進資金の主な融資条件は以下の通りです。

| 項目                 | 内容                                                               |
| :------------------- | :----------------------------------------------------------------- |
| **資金使途**         | 運転資金                                                           |
| **融資限度額**       | 5,000万円                                                          |
| **融資利率（固定）** | **年1.8%以内**                                                       |
| **融資期間**         | **6か月以内**                                                        |
| **返済方法**         | 一括返済または分割返済                                                 |
| **担保**             | 必要に応じて                                                       |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                             |
| **信用保証料率**     | **年0.45%～1.90%** （※信用保証の利用は金融機関の任意です）            |

※本融資に対する**県の信用保証料補助はありません**。

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会（保証を利用する場合）による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   輸出入に関する事業内容を確認することができる書類
*   財務書類（直近2期分の決算書（確定申告書）の控え等）
*   **（信用保証ありの場合）** 【第2号様式】神奈川県中小企業制度融資申込書
*   **（信用保証なしの場合）** 【第3号様式】神奈川県中小企業制度融資申込書

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
