## 神奈川県 制度融資「[再生支援融資（つなぎ枠）](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/saiseisien_tunagiwaku.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**再生支援機関の指導・助言**を受けながら**事業再生**を図る中小企業者の皆様が、再生計画等の策定中に事業継続に必要な資金を調達するための「再生支援融資（つなぎ枠）」について、その詳細をご案内いたします。

### ご利用いただける方

*   **神奈川県信用保証協会の保証付き融資**を利用しつつ、**再生支援機関**（※）の指導または助言を受け事業再生を図る[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)

※ 再生支援機関：中小企業活性化協議会、経営サポート会議など

※協同組合等が対象となるかは、金融課にご確認ください。

### 融資条件

再生支援融資（つなぎ枠）の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                           |
| :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金<br>（※再生支援機関による**再生計画等の策定中に事業を継続するために必要な資金**に限ります）                                        |
| **融資限度額**       | 2億8,000万円                                                                                                                                   |
| **融資利率**         | **固定金利：年2.1%以内** （※金融機関所定の変動金利も可）                                                                                              |
| **融資期間**         | **3年以内**                                                                                                                                    |
| **返済方法**         | 分割返済（6か月以内の据置き可）<br>※融資期間1年以内の場合は一括返済も可                                                                                  |
| **担保**             | 必要に応じて                                                                                                                                 |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                                                       |
| **信用保証料率**     | **普通保証：年1.76％**<br>**無担保保証：年1.408％**<br>※県の補助後の料率です。国の事業再生円滑化関連保証（経営改善・再生支援つなぎ資金保証）が適用されます。 |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）
*   【別記様式】事業再生に関する計画書(事業再生円滑化関連保証用）
*   再生支援機関が指導または助言を開始したことを証する書面

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し
