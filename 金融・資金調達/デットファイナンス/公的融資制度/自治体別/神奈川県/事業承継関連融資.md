## 神奈川県 制度融資「[事業承継関連融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/jigyousyoukei.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**事業承継**の様々な段階にある事業者の皆様を資金面から支援する「事業承継関連融資」について、その詳細をご案内いたします。

### ご利用いただける方

以下のいずれかに該当する[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)が対象となります。

*   ア：神奈川県事業承継・引継ぎ支援センター、金融機関、認定経営革新等支援機関又は県信用保証協会の支援を受け、**10年以内の事業承継計画**を策定し計画の実行に取り組む方
*   イ：**事業承継をした日から5年未満**で、事業計画を策定し経営の安定化や事業の拡大に取り組む方
*   ウ：中小企業経営承継円滑化法に基づく**県の認定**を受けた中小企業者（※）
*   エ：上記ウに該当する中小企業者の**代表者個人**
*   オ：事業活動の継続に支障が生じている他の中小企業者の経営の承継を実施するため、中小企業経営承継円滑化法に基づく**県の認定**を受けた中小企業者（※）
*   カ：上記オと同様の目的で、同法に基づく**県の認定**を受けた**事業を営んでいない個人**
*   キ：事業承継計画に基づき、事業会社の株式取得のため設立され、持株会社の発行済議決権株式総数の3分の2以上の株式を後継者が保有している**持株会社**
*   ク：以下の(1)又は(2)に該当し、**下記「一定の要件」**を満たす中小企業者及び協同組合等（**個人事業者を除く**）
    1.  保証申込受付日から**3年以内に事業承継を予定**する法人
    2.  令和2年1月1日から令和7年3月31日までに**事業承継を実施**し、事業承継日から3年を経過していない法人
*   ケ：**3年以内に事業承継を予定**し、中小企業経営承継円滑化法第12条に基づく**経済産業大臣の認定**を受け、**下記「一定の要件」**を満たす中小企業者（**個人事業者を除く**）

※ウ、オ、カ、ケの対象となる中小企業者からは、NPO法人、医療法人は除きます。

#### 一定の要件（上記ク、ケに該当する場合）

以下のすべてを満たすことが必要です。

1.  資産超過であること
2.  EBITDA有利子負債倍率が10倍以内であること
3.  法人・個人の分離がなされていること
4.  返済緩和している借入金がないこと

### 融資条件

事業承継関連融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                                                                                                                     |
| :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金 （※キは設備資金のみ、ケは事業承継前の経営者保証付融資の借換資金のみ）                                                                                                                                                       |
| **融資限度額**       | **【ア,イ,エ,カ,ク(1),ク(2)】8,000万円**<br>**【ウ,オ,ケ】別枠 8,000万円**<br>**【キ】2億8,000万円**                                                                                                                                              |
| **融資利率（固定）** | **年1.8%以内**                                                                                                                                                                                                                            |
| **融資期間**         | **【運転資金】**<br>・1年超10年以内（ア,イ,ウ,エ,オ,カ）<br>・10年以内（ク(1),ク(2),ケ）<br>**【設備資金】**<br>・1年超10年以内（ア,イ）<br>・1年超15年以内（ウ,エ,オ,カ,キ）<br>・10年以内（ク(1)）                                                              |
| **返済方法**         | 分割返済 （据置期間：1年以内。ただしキの場合は1年6か月以内）                                                                                                                                                                                   |
| **担保**             | 必要に応じて                                                                                                                                                                                                                            |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要<br>（※ク(1)、ク(2)、ケは**経営者保証が不要**となります）                                                                                                                                           |
| **信用保証料率**     | **年0.45%～1.52%** （※県の補助後の料率。ただしカを除く）<br>（※ク(1)、ク(2)、ケで中小企業活性化協議会及び事業承継・引継ぎ支援センターによる確認を受けた場合は、**年0.20％～0.92％**） |

### 企業経営の未病改善に取り組む皆様へ ～信用保証料の割引～

「<a href="https://www.pref.kanagawa.jp/documents/10454/checksheet_sougyouki.xlsx" target="_blank">企業経営の未病CHECKシート</a>」のチェック結果をもとに、商工会・商工会議所または神奈川産業振興センターの支援を受けながら経営課題の改善に取り組むと、**信用保証料がさらに割り引かれます**。
詳しくは[こちら](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/me-byo.html)をご覧ください。

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【対象者アの場合】**

*   【様式14-1】ライフステージ別資金（再生期）（事業承継関連融資）事業承継計画書

**【対象者イの場合】**

*   【様式14-2】ライフステージ別資金（再生期）（事業承継関連融資）事業計画書（事業承継後）
*   要件の事業承継日の確認資料（例：個人事業者の場合は開業・廃業等届出書の写し、法人の場合は商業登記簿謄本）

**【対象者ウ、エ、オ、カ、ケの場合】**

*   県の認定書及び認定申請書の写し

**【対象者キの場合】**

*   【様式14-3】ライフステージ別資金（再生期）（事業承継関連融資）事業承継計画書(持株会社方式）

**【対象者ク(1)、ク(2)の場合】**

*   国の定める事業承継計画書
*   国の定める財務用件等確認書
*   〈必要に応じて〉国の定める借換債務等確認書
*   〈必要に応じて〉国の定める他行借換依頼書兼確認書
*   （ク(2)の場合のみ）要件の事業承継日の確認資料（法人の場合は商業登記簿謄本）

**【対象者ケの場合】**

*   国の定める事業承継計画書
*   国の定める借換債務等確認書
*   〈必要に応じて〉国の定める他行借換依頼書兼確認書

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
