## 神奈川県 制度融資「[条件変更改善借換融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p1123429.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**神奈川県中小企業制度融資の保証付き融資**について**返済条件の緩和（条件変更）**を受けている事業者の方で、**経営改善**に取り組む方を対象とした「条件変更改善借換融資」について、その詳細をご案内いたします。

### ご利用いただける方

以下の**すべての要件**を満たす[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)が対象となります。

1.  **神奈川県中小企業制度融資の保証付き融資**の利用者であること。
2.  上記融資について、**返済条件の緩和（条件変更）**を行っていること。
3.  **認定経営革新等支援機関**（金融機関や税理士等の専門家）の支援を受けつつ、自ら**事業計画**の策定並びに計画の実行及び進捗の報告を行うこと。

### 融資条件

条件変更改善借換融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                          |
| :------------------- | :---------------------------------------------------------------------------------------------------------- |
| **資金使途**         | **借換資金**（事業計画の内容に応じて、新規の融資分を含むことができます）                                          |
| **融資限度額**       | 8,000万円                                                                                                     |
| **融資利率（固定）** | ・10年以内： **年2.0%以内**<br>・10年超15年以内： **年2.5%以内**                                                     |
| **融資期間**         | 15年以内                                                                                                      |
| **返済方法**         | 分割返済（1年以内の据置き可。ただし、新規の融資分を含む場合は**2年以内**の据置き可）                                  |
| **担保**             | 必要に応じて                                                                                              |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                      |
| **信用保証料率**     | **年0.45%～1.52%** （※神奈川県による補助後の料率です。国の伴走支援型特別保証制度が適用されます）                  |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html?mode=preview#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）
*   [状況説明書](https://www.pref.kanagawa.jp/documents/10475/risk_karikae_jyokyosetumeisyo.pdf) (PDF：93KB)
*   事業計画書（任意の様式）
*   認定経営革新等支援機関による支援内容を記載した書面（事業計画書に記載されている場合は不要）

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合（新規融資分を含む場合）】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
