## 神奈川県 制度融資「[生産性向上支援融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p1064137.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**経営力向上計画**や**先端設備等導入計画**に基づき、**生産性の向上**を図る事業者の皆様を対象とした「生産性向上支援融資」について、その詳細をご案内いたします。

### ご利用いただける方

以下のいずれかに該当する方が対象となります。

*   ア：国の認定を受けた**経営力向上計画**に従って、経営力向上を図る[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)（NPO法人、医療法人を除く）及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)
*   イ：市町村の認定を受けた**先端設備等導入計画**に従って、先端設備等を導入する[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)（NPO法人、医療法人を除く）及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)
    *   （注）市町村は、経済産業大臣から同意を得た導入促進基本計画を作成した市町村（特定市町村）に限ります。
*   ウ：上記ア又はイに加え、**生産効率向上設備の導入**により**省エネ効果**が見込まれる事業計画について取扱金融機関が確認した[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)（NPO法人、医療法人を除く）及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)

### 融資条件

生産性向上支援融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となり、通常の保証限度額とは**別枠**で保証が受けられます。

| 項目                 | 内容                                                                                                                                                            |
| :------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金<br>（ウの場合は、運転資金は設備設置に係る経費に限る）                                                                                             |
| **融資限度額**       | **別枠 8,000万円**                                                                                                                                                |
| **融資利率（固定）** | **【ア、イの場合】年2.0%以内**<br>**【ウ（省エネ効果）の場合】年1.8％以内**                                                                                               |
| **融資期間**         | 運転資金：10年以内<br>設備資金：15年以内                                                                                                                          |
| **返済方法**         | 分割返済（1年以内の据置き可。ウの場合は**2年以内**の据置き可）<br>※融資期間1年以内の場合は一括返済も可                                                                           |
| **担保**             | 必要に応じて                                                                                                                                                    |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                                                                        |
| **信用保証料率**     | **年0.34%** （※神奈川県による補助後の料率です。国の経営力向上関連保証制度、または先端設備等導入計画に係る保証制度が適用されます） |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html?mode=preview#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【対象者アの場合】**

*   認定経営力向上計画に係る認定申請書の写し

**【対象者イの場合】**

*   認定先端設備等導入計画に係る認定申請書の写し

**【対象者ウの場合】**

*   【様式16】「生産性向上支援融資」事業計画書（融資対象（ウ）用）

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し
