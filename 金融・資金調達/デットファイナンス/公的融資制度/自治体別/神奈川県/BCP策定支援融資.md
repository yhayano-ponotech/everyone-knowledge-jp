## 神奈川県 制度融資「[BCP策定支援融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/bcp.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、自然災害や感染症拡大などの緊急事態に備え、**事業継続計画（BCP）の策定やBCPに基づく対策**を行う事業者の皆様を対象とした「BCP策定支援融資」について、その詳細をご案内いたします。

### ご利用いただける方

以下のいずれかに該当する[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)が対象となります。

*   ア：**事業継続計画（BCP）の策定**やBCPに基づく対策を行う方
*   イ：国の**「事業継続力強化計画」**の認定を受けた方
*   ウ：国の**「連携事業継続力強化計画」**の認定を受けた方

### 融資条件

BCP策定支援融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                                                                                                         |
| :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金                                                                                                                                                                                                             |
| **融資限度額**       | **【アの場合】8,000万円**<br>**【イ、ウの場合】別枠 8,000万円** （※通常の保証限度額とは別枠）                                                                                                                                    |
| **融資利率（固定）** | **年1.8%以内**                                                                                                                                                                                                                 |
| **融資期間**         | 運転資金：1年超10年以内<br>設備資金：1年超15年以内                                                                                                                                                                               |
| **返済方法**         | 分割返済（1年以内の据置き可）                                                                                                                                                                                                    |
| **担保**             | 必要に応じて                                                                                                                                                                                                                 |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                                                                                                                                       |
| **信用保証料率**     | **【アの場合】年0.45%～1.52%** （※神奈川県による補助後の料率です）<br>**【イ、ウの場合】年0.68%** （※本融資に対する県の信用保証料補助はありません。国の事業継続力強化関連保証、または連携事業継続力強化計画関連保証が適用されます） |

### 企業経営の未病改善に取り組む皆様へ ～信用保証料の割引～

「<a href="https://www.pref.kanagawa.jp/documents/10454/checksheet_sougyouki.xlsx" target="_blank">企業経営の未病CHECKシート</a>」のチェック結果をもとに、商工会・商工会議所または神奈川産業振興センターの支援を受けながら経営課題の改善に取り組むと、**信用保証料がさらに割り引かれます**。
詳しくは[こちら](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/me-byo.html)をご覧ください。

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【対象者アの場合】**

*   【様式3】事業振興資金（BCP策定支援融資）融資対象確認（申請）書

**【対象者イの場合】**

*   事業継続力強化計画に係る認定申請書の写し

**【対象者ウの場合】**

*   連携事業継続力強化計画に係る認定申請書の写し

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
