## 神奈川県 制度融資「[事業再生サポート融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p846412.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**事業再生**に取り組む事業者の皆様を対象とした「事業再生サポート融資」について、その詳細をご案内いたします。

### ご利用いただける方

*   **中小企業活性化協議会等**の指導又は助言や**経営サポート会議**による検討により作成された**事業再生計画**に従って事業再生に取り組む[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)

※協同組合等も対象となります。

### 融資条件

事業再生サポート融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となり、通常の保証限度額とは**別枠**で保証が受けられます。

| 項目                 | 内容                                                                                                                                          |
| :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------ |
| **資金使途**         | 運転資金・設備資金 （※事業再生の計画実施に必要な資金に限ります）                                                                                      |
| **融資限度額**       | **別枠 2億8,000万円**                                                                                                                         |
| **融資利率（固定）** | ・10年以内： **年2.3%以内**<br>・10年超15年以内： **年2.8%以内**                                                                                     |
| **融資期間**         | 15年以内                                                                                                                                      |
| **返済方法**         | 分割返済（1年以内の据置き可）<br>※融資期間1年以内の場合は一括返済も可                                                                                   |
| **担保**             | 必要に応じて                                                                                                                                |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                                                      |
| **信用保証料率**     | **年0.80%** または **年1.00%**<br>※本融資に対する県の信用保証料補助はありません。国の経営改善サポート保証（事業再生計画実施関連保証）が適用されます。 |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   （独法）中小企業基盤整備機構、中小企業活性化協議会、経営サポート会議等の指導・助言を受けて作成した**事業再生の計画書**（任意の書式）
*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**
（※NPO法人が対象となるかは、上記「ご利用いただける方」の定義と合わせて金融課にご確認ください）
*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
