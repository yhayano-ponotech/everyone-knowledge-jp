## 神奈川県 制度融資「[かながわイノベーション戦略的支援融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/kanagawainobesyonn.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**「かながわイノベーション戦略的支援事業」の認定**を受けた事業者の皆様を対象とした「かながわイノベーション戦略的支援融資」について、その詳細をご案内いたします。

### ご利用いただける方

以下のいずれかに該当する方が対象となります。

*   ア：「かながわイノベーション戦略的支援事業」の認定を受けた[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)
*   イ：上記アに該当する方のうち、「[創業支援融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p848390.html)」の融資対象ア～クの要件を満たす創業者、[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)（NPO法人を除く）

### 融資条件

かながわイノベーション戦略的支援融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                      |
| :------------------- | :-------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金                                                                                                                        |
| **融資限度額**       | **【アの場合】8,000万円**<br>**【イの場合】3,500万円** （※創業支援融資の融資額と合算されます）                                                      |
| **融資利率（固定）** | **年1.8%以内**                                                                                                                            |
| **融資期間**         | 1年超10年以内                                                                                                                             |
| **返済方法**         | 分割返済（1年以内の据置き可）                                                                                                               |
| **担保**             | 必要に応じて物的担保を提供する<br>（ただし、イに該当し、責任共有対象外で利用する場合は、物的担保は不要）                                                   |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                                                  |
| **信用保証料率**     | **年0.40%～1.33%**<br>**【イ（創業者等）の場合】年0.00%**<br>※県の補助及び神奈川県信用保証協会の割引後の料率です。国の創業関連保証制度等が適用されます。 |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   客観的に事業を開始したことを証する書類の写し（例：開業後の個人事業者は、個人事業開業届出書の写し）
*   **「かながわイノベーション戦略的支援事業」認定書の写し**

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【創業前又は創業後1年未満の場合】**

*   [創業・再挑戦計画書](https://www.pref.kanagawa.jp/documents/16157/sougyou_saityousen_keikakusyo.xls) （エクセル：60KB）

**【決算を迎えている場合】**

*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
