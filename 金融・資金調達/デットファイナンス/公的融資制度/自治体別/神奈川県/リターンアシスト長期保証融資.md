## 神奈川県 制度融資「[リターンアシスト長期保証融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/retarn_a.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**返済条件の緩和（条件変更）**を受けている神奈川県信用保証協会の保証付き融資について、経営改善計画に基づき**借換えを行うことで借入の正常化**を図る事業者の皆様を対象とした「リターンアシスト長期保証融資」について、その詳細をご案内いたします。

### ご利用いただける方

以下の**すべての要件**を満たす[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)が対象となります。

1.  **神奈川県信用保証協会の保証付き融資**の利用者であること。
2.  上記融資について、**返済条件の緩和（条件変更）**を行っていること。
3.  **経営改善計画**の取組みの一環として、当該条件変更中の融資残高を本融資により**借り換える**こと。

### 融資条件

リターンアシスト長期保証融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                     |
| :------------------- | :--------------------------------------------------------------------------------------- |
| **資金使途**         | **借換資金**及び**運転資金**（当該借換に必要な諸費用相当額に限る）                               |
| **融資限度額**       | 1億6,000万円<br>（※リターンアシスト長期保証融資（別枠保証）と合算した限度額）                    |
| **融資利率（固定）** | ・10年以内： **年2.0％以内**<br>・10年超15年以内： **年2.5％以内**                                  |
| **融資期間**         | 15年以内                                                                                 |
| **返済方法**         | 分割返済                                                                                 |
| **担保**             | 必要に応じて                                                                             |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                   |
| **信用保証料率**     | **年0.45%～1.52%** （※神奈川県による補助後の料率です。国の条件変更改善型借換保証制度が適用されます） |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）
*   経営改善計画書等その他神奈川県信用保証協会の定める書類（※書式は保証協会へお問い合わせください）

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面

### その他

*   新規保証の場合、原則として6か月間の静観期間があります。
