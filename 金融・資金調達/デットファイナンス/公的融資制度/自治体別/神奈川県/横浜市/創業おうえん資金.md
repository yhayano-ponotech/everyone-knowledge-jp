## 横浜市中小企業融資制度「[創業おうえん資金](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/venture-sougyo.html)」のご案内

横浜市では、市内中小企業および小規模事業者の皆様の事業活動を支援するため、「横浜市中小企業融資制度」を提供しております。本稿では、これから横浜市内で創業を目指す方、または創業後間もない方を対象とした「創業おうえん資金」について、その詳細をご案内いたします。

### 創業おうえん資金とは

創業おうえん資金は、横浜市内での創業に必要な運転資金および設備資金の調達を支援する融資制度です。横浜市中小企業融資制度の基本要件を満たす、創業予定者または創業後5年未満の中小企業者が対象となります。本資金には、「経営者保証有」タイプと、一定の要件を満たす場合に経営者保証が不要となる「経営者保証不要特別」タイプの2種類があります。

**※NPO法人の方は、本資金のご利用はできません。**

### 融資条件

| **利率（年利）** | **固定金利：年2.3％以内**                                               |
| **融資期間**   | 運転資金：10年以内<br>設備資金：10年以内<br>（いずれも据置期間12か月以内を含む） |
| **担保**       | 原則として不要                                                       |
| **保証料率**   | **助成前**：年0.4％<br>**助成後**：年0.3％（横浜市が年0.1％助成）<br>※横浜市信用保証協会による保証料率割引（0.4％）適用後の料率 |

### 必要書類

お申込みにあたっては、原則として以下の書類をご提出いただきます。

**【全タイプ共通】**

1.  信用保証委託申込書（横浜市信用保証協会所定様式）
2.  申込人（個人・法人）および連帯保証人（※1）の印鑑証明書（※2, 3）
3.  納税証明書（※2）、または領収書の写し、eLTAXや地方税お支払いサイトの納付済確認画面
4.  決算書（確定申告書）の写し（原則、直近2期分。創業前・創業後間もない場合は不要）
5.  【法人の場合】履歴事項全部証明書（商業登記簿謄本）または登記情報提供サービスで取得したもの（※2, 3。設立前は定款案等）
6.  許認可証等の写し（許認可等が必要な事業の場合）
7.  【設備資金の場合】見積書およびレイアウト・カタログ等の写し

*   ※1：連帯保証人が必要となる場合があります（経営者保証有タイプの場合）。
*   ※2：各種証明書は発行後3ヶ月以内の最新のものをご用意ください。納税証明書は[オンライン申請](https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/shizei-shomei/online/gaiyou.html)も可能です。
*   ※3：横浜市信用保証協会への申込時は写しでの提出が可能な場合があります。

### 融資実行までの流れ

融資実行までの標準的な手続きは以下の通りです。

1.  **ご相談・お申込み**: お取引のある、または最寄りの取扱金融機関にご相談の上、必要書類（創業計画書含む）を提出し、お申込みください。
2.  **金融機関による審査**: 取扱金融機関にて融資審査が行われます。
3.  **信用保証協会による保証審査**: 金融機関からの依頼に基づき、横浜市信用保証協会にて保証審査が行われます。
4.  **融資実行**: 金融機関および信用保証協会の審査を経て承認された場合、取扱金融機関より融資が実行されます。

※本制度のご利用にあたっては、取扱金融機関および横浜市信用保証協会の審査が必要です。記載内容は概要であり、融資実行・保証承諾をお約束するものではありません。
