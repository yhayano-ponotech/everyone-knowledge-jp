## 横浜市中小企業融資制度「[事業承継資金（経営者保証不要特別）](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/syoukei-keieisha.html)」のご案内

横浜市では、市内中小企業および小規模事業者の皆様の事業活動を支援するため、「横浜市中小企業融資制度」を提供しております。本稿では、「事業承継資金」のうち、**一定の財務要件等を満たす法人**を対象に、**経営者の連帯保証が不要**となる「事業承継資金（経営者保証不要特別）」について、その詳細をご案内いたします。

### 事業承継資金（経営者保証不要特別）とは

本資金は、事業承継に取り組む法人の資金調達を支援する制度です。特に、**定められた財務要件等をクリア**することで、**経営者の個人保証なし**で融資を受けられる点が大きな特徴です。事業承継計画の策定・実行、承継後の借換、M&A等による承継準備など、様々な事業承継の局面で活用いただけます。横浜市による保証料の助成も設けられています。

**※本資金は法人のみが対象です。**

### 融資条件

事業承継資金（経営者保証不要特別）の主な融資条件は以下の通りです。

| 項目         | 内容                                                                 |
| :----------- | :------------------------------------------------------------------- |
| **融資対象者** | [横浜市中小企業融資制度の融資申込要件](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/yushi.html#moushikomi)を全て満たし、かつ以下の**追加要件（1～4のいずれか）**及び**財務要件等（5）**を全て満たす**法人**<br>**【追加要件】**<br>1. **事業承継計画**を有する（これから3年以内に実施予定）<br>2. **事業承継を既に実施**（R2.1.1～R7.3.31）し、3年を経過していない<br>   *(1, 2は国の「事業承継特別保証制度」対象)*<br>3. **事業承継計画**（これから3年以内に実施予定）を有し、既存借入金の**借換**を行う<br>   *(国の「経営承継借換関連保証制度」対象)*<br>4. **M&A等による事業承継**をこれから実施するため、株式や事業用資産等の取得資金を必要とする<br>   *(国の「経営承継準備関連保証制度」対象)*<br>**【財務要件等（5）】** 次の(1)～(4)を全て満たすこと<br>   (1) **資産超過**であること<br>   (2) **EBITDA有利子負債倍率が10倍以内**であること<br>       *※EBITDA有利子負債倍率＝（借入金・社債－現預金）÷（営業利益＋減価償却費）*<br>   (3) **法人と経営者の分離**がなされていること<br>   (4) **返済緩和**している借入金がないこと<br>   *※(1)～(3)は直近決算時、(4)は申込日時点での充足が必要。*<br>   *※申込金融機関との与信取引があることが必要。* |
| **資金使途**   | 事業承継計画の実施に必要な資金<br>※対象者区分により制限あり。特に融資対象者2は事業承継前の個人保証付き既往借入金の借換資金、融資対象者3は認定日から承継日までの間の個人保証付き既往借入金の借換資金に限る。 |
| **融資額**     | 2億8,000万円以内                                                        |
| **利率（年利）** | 取扱金融機関の所定利率                                                 |
| **融資期間**   | 運転資金：10年以内<br>設備資金：10年以内<br>（いずれも据置期間12か月以内を含む） |
| **担保**       | 必要に応じて                                                         |
| **保証料率**   | **【神奈川県中小企業活性化協議会等専門家による確認を受けた場合】**<br>・助成前：年0.20％～1.15％<br>・助成後：**年0.00％～0.90％**（横浜市が**年0.25％**助成）<br>**【上記専門家による確認を受けていない場合】**<br>・助成前：年0.45％～1.90％<br>・助成後：**年0.20％～1.65％**（横浜市が**年0.25％**助成） |
| **連帯保証人**   | **不要**                                                               |

### 必要書類

お申込みにあたっては、原則として以下の書類をご提出いただきます。

**【全対象者共通】**

1.  信用保証委託申込書（横浜市信用保証協会所定様式）
2.  申込人（法人）の印鑑証明書（※1, 2）
3.  納税証明書（※2）、または領収書の写し、eLTAXや地方税お支払いサイトの納付済確認画面
4.  決算書（確定申告書）の写し（原則、直近2期分）
5.  履歴事項全部証明書（商業登記簿謄本）または登記情報提供サービスで取得したもの（※1, 2）
6.  許認可証等の写し（許認可等が必要な事業の場合）
7.  【設備資金の場合】見積書およびレイアウト・カタログ等の写し

*   ※1：証明書は発行後3ヶ月以内の最新のものをご用意ください。
*   ※2：横浜市信用保証協会への申込時は写しでの提出が可能な場合があります。納税証明書は[オンライン申請](https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/shizei-shomei/online/gaiyou.html)も可能です。

### 融資実行までの流れ

融資実行までの標準的な手続きは以下の通りです。

1.  **ご相談・お申込み**: お取引のある、または最寄りの取扱金融機関にご相談の上、必要書類を提出し、お申込みください。
2.  **金融機関による審査**: 取扱金融機関にて融資審査が行われます。
3.  **信用保証協会による保証審査**: 金融機関からの依頼に基づき、横浜市信用保証協会にて保証審査が行われます。
4.  **融資実行**: 金融機関および信用保証協会の審査を経て承認された場合、取扱金融機関より融資が実行されます。

※本制度のご利用にあたっては、取扱金融機関および横浜市信用保証協会の審査が必要です。記載内容は概要であり、融資実行・保証承諾をお約束するものではありません。
