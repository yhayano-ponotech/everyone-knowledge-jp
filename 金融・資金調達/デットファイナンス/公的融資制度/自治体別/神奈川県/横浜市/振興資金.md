## 横浜市中小企業融資制度「[振興資金](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/sinko.html)」のご案内

横浜市では、市内中小企業および小規模事業者の皆様の事業活動に必要な資金調達を支援するため、「横浜市中小企業融資制度」を設けております。本稿では、同制度の主要な融資メニューの一つである「振興資金」について、その詳細をご案内いたします。

### 振興資金とは

振興資金は、横浜市内の中小企業者が事業運営に必要な運転資金および設備資金を円滑に調達することを目的とした融資制度です。幅広い資金使途に対応しており、横浜市中小企業融資制度の基本的な要件を満たす多くの中小企業者にご利用いただけます。

### 融資条件

振興資金の主な融資条件は以下の通りです。

| 項目         | 内容                                                                 |
| :----------- | :------------------------------------------------------------------- |
| **融資対象者** | [横浜市中小企業融資制度の融資申込要件](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/yushi.html#moushikomi)を全て満たす中小企業者 |
| **資金使途**   | 運転資金および設備資金                                                   |
| **融資額**     | 2億8,000万円以内（協同組合等は4億8,000万円以内）                           |
| **利率（年利）** | 固定金利または変動金利から選択<br>**【固定金利】**<br>・1年以内： 年1.9％以内<br>・1年超3年以内： 年2.4％以内<br>・3年超5年以内： 年2.6％以内<br>・5年超7年以内： 年2.7％以内<br>・7年超15年以内： 年2.9％以内<br>・15年超20年以内： 年3.0％以内<br>**【変動金利】**<br>・短期プライムレート＋0.7％以内                                |
| **融資期間**   | 運転資金：7年以内<br>設備資金：20年以内<br>（いずれも据置期間12か月以内を含む） |
| **担保**       | 必要に応じて                                                         |
| **保証料率**   | 年0.45％～1.90％<br>※[「脱炭素割」](https://www.city.yokohama.lg.jp/business/kigyoshien/yushiseido/yushiseido/shinko_datutanso.html)の適用により、保証料助成が受けられる場合があります。 |

### 必要書類

お申込みにあたっては、原則として以下の書類をご提出いただきます。

1.  信用保証委託申込書（横浜市信用保証協会所定様式）
2.  申込人（個人・法人）および連帯保証人（※1）の印鑑証明書（※2, 3）
3.  納税証明書（※2）、または領収書の写し、eLTAXや地方税お支払いサイトの納付済確認画面
4.  決算書（確定申告書）の写し（原則、直近2期分）
5.  【法人の場合】履歴事項全部証明書（商業登記簿謄本）または登記情報提供サービスで取得したもの（※2, 3）
6.  許認可証等の写し（許認可等が必要な事業の場合）
7.  【設備資金の場合】見積書およびレイアウト・カタログ等の写し

*   ※1：連帯保証人が必要となる場合があります。
*   ※2：各種証明書は発行後3ヶ月以内の最新のものをご用意ください。納税証明書は[オンライン申請](https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/zeikin/shizei-shomei/online/gaiyou.html)も可能です。
*   ※3：横浜市信用保証協会への申込時は写しでの提出が可能な場合があります。

### 融資実行までの流れ

融資実行までの標準的な手続きは以下の通りです。

1.  **ご相談・お申込み**: お取引のある、または最寄りの取扱金融機関にご相談の上、必要書類を提出し、お申込みください。
2.  **金融機関による審査**: 取扱金融機関にて融資審査が行われます。
3.  **信用保証協会による保証審査**: 金融機関からの依頼に基づき、横浜市信用保証協会にて保証審査が行われます。
4.  **融資実行**: 金融機関および信用保証協会の審査を経て承認された場合、取扱金融機関より融資が実行されます。

※本制度のご利用にあたっては、取扱金融機関および横浜市信用保証協会の審査が必要です。記載内容は概要であり、融資実行・保証承諾をお約束するものではありません。
