## 神奈川県 制度融資「[小規模クイック融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p864772.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、迅速な資金調達ニーズに対応する**小規模事業者向け**の「小規模クイック融資」について、その詳細をご案内いたします。

### ご利用いただける方

*   従業員数30人（卸売業・小売業・サービス業の場合は10人）以下の[**中小企業者**](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)

※NPO法人も利用可能です。

### 融資条件

小規模クイック融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                                                                                                         |
| :------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金                                                                                                                                                                                                             |
| **融資限度額**       | **4,000万円**<br>**【特別小口】2,000万円** （上記4,000万円の内枠、担保・連帯保証人不要）                                                                                                                                            |
| **融資利率**         | **【固定金利】**<br>・1年以内： 金融機関所定の利率<br>・1年超5年以内： **年2.0%以内**<br>・5年超7年以内： **年2.2％以内**<br>・7年超10年以内： **年2.5％以内**<br>**【変動金利】**<br>・全融資期間において金融機関所定の変動金利も可                         |
| **融資期間**         | 10年以内                                                                                                                                                                                                                       |
| **返済方法**         | 分割返済（6か月以内の据置き可）<br>※融資期間1年以内の場合は一括返済も可                                                                                                                                                                |
| **担保**             | 必要に応じて（※特別小口の場合は不要）                                                                                                                                                                                               |
| **保証人**           | 原則として法人の代表者以外の連帯保証人は不要（※特別小口の場合は不要）                                                                                                                                                              |
| **信用保証料率**     | **【通常枠】年0.45%～1.52%**<br>**【特別小口】年0.8％**<br>※県の補助後の料率です。<br>※[企業経営の未病改善](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/me-byo.html)に取り組む場合は、**さらに保証料が割り引かれます**。（下記参照） |

### 企業経営の未病改善に取り組む皆様へ ～信用保証料の割引～

「<a href="https://www.pref.kanagawa.jp/documents/10454/checksheet_sougyouki.xlsx" target="_blank">企業経営の未病CHECKシート</a>」のチェック結果をもとに、商工会・商工会議所または神奈川産業振興センターの支援を受けながら経営課題の改善に取り組むと、**信用保証料がさらに割り引かれます**。
詳しくは[こちら](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/me-byo.html)をご覧ください。

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

*   [ご利用の流れ](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/goriyounonagare.html)

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
