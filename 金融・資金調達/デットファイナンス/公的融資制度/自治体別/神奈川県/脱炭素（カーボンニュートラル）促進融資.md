## 神奈川県 制度融資「[脱炭素（カーボンニュートラル）促進融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/datsutanso_yusi.html)」のご案内

神奈川県では、県内の中小企業および小規模事業者の皆様の事業活動を支援するため、各種制度融資を提供しております。本稿では、**脱炭素（カーボンニュートラル）社会の実現に向けた取組**を行う事業者の皆様を対象とした「脱炭素（カーボンニュートラル）促進融資」について、その詳細をご案内いたします。

### ご利用いただける方

以下のいずれかに該当する方が対象となります。

*   ア：**県から認定**を受けて、**環境負荷低減のための取組**（※1）を行う[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)（NPO法人を含む）及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)
*   イ：**県から認定**を受けて、**産業廃棄物処理施設の整備**を行う[中小企業者](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#chusyo)（NPO法人を含む）及び[協同組合等](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p850147.html#kumiai)
*   ウ：[ソーラー発電等促進融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p847671.html)の対象者
*   エ：[地球温暖化対策省エネ設備等導入融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/ondankataisaku_yusi.html)の対象者
*   オ：[電気自動車等・充電設備導入融資](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/ev_yusi.html)の対象者

（※1）取組例：
*   低公害車の購入
*   公害防除または環境負荷低減のための施設・設備の設置や改善
*   公害防止のための工場等の移転 など

#### 認定に関するお問い合わせ先

*   **対象者ア**：神奈川県環境農政局 環境部 環境課 （TEL 045-210-4107）
*   **対象者イ**：神奈川県環境農政局 環境部 資源循環推進課 （TEL 045-210-4147）

### 融資条件

脱炭素（カーボンニュートラル）促進融資の主な融資条件は以下の通りです。本融資は**神奈川県信用保証協会の保証付き**となります。

| 項目                 | 内容                                                                                                                                                                 |
| :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資金使途**         | 運転資金・設備資金<br>（※ただし、運転資金は同時に借り入れる設備資金の2分の1が限度額となります）                                                                                  |
| **融資限度額**       | **【アの場合】8,000万円** （協同組合等は1億2,000万円）<br>**【イの場合】2億円**                                                                                               |
| **融資利率（固定）** | **年1.8%以内**                                                                                                                                                        |
| **融資期間**         | 運転資金：1年超7年以内<br>設備資金：1年超10年以内                                                                                                                       |
| **返済方法**         | 分割返済（1年以内の据置き可）                                                                                                                                            |
| **担保**             | 必要に応じて                                                                                                                                                       |
| **保証人**           | 原則として法人代表者以外の連帯保証人は不要                                                                                                                             |
| **信用保証料率**     | **年0.125%～0.85%** （※県の補助及び神奈川県信用保証協会の割引後の料率です）<br>**【公害防止保証を適用する場合】年1.15％**<br>※国の環境配慮型経営支援保証等が適用されます。 |

### お申込み

下記「必要書類」をそろえ、[取扱金融機関](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p844423.html)に直接お申し込みください。
取扱金融機関及び神奈川県信用保証協会による審査の後、融資が実行されます。

**注記：審査の結果、ご希望に添えない場合があります。**

### 必要書類

県所定の様式（【】がついているもの）は[様式一覧](https://www.pref.kanagawa.jp/docs/m6c/cnt/f5782/p892663.html?mode=preview#list)からダウンロードが可能です。

**【共通】**

*   【第2号様式】神奈川県中小企業制度融資申込書
*   【様式8】政策連動資金（脱炭素（カーボンニュートラル）促進融資）対象認定（申請）書
*   財務書類（直近2期分の決算書（確定申告書）の控え等）

**【初めて神奈川県信用保証協会を利用する場合】**

*   印鑑証明書（申込者及び連帯保証人）
*   〈法人事業の場合〉定款の写し及び商業登記簿謄本（履歴事項全部証明書）
*   〈必要に応じて〉住民票抄本（本籍地の記載は不要）

**【許認可等の必要な事業の場合】**

*   許認可証等の写し

**【設備資金の場合】**

*   見積書の写し

**【NPO法人の場合】**

*   事業報告書
*   計算書類（活動計算書及び貸借対照表）
*   年間役員名簿
*   社員のうち10人以上の者の氏名及び住所を記載した書面
